# 💰 Personal Expense Tracker (Python + pandas)

A simple command-line app to track your daily expenses using Python and pandas.

## 📦 Features
- Add new expenses (amount, category, notes)
- View all saved expenses
- Total spending per category
- Data stored in a CSV file

## 🛠️ Tech Used
- Python
- pandas

## 🚀 How to Run
```bash
pip install pandas
python tracker.py
